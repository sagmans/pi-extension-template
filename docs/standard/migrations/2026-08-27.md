# 2026-08-27 Baseline Adoption

## Purpose

Baseline adoption establishes the first date-versioned standard for a public npm package containing one Pi extension.

## Required families

Adopt or deliberately adapt:

- Private reference guard until target publication is configured
- TypeScript source entrypoint and Pi package manifest
- Current-LTS Node and committed npm lockfile
- Biome, strict TypeScript, Vitest, and 80% global coverage
- High-or-critical dependency audit gate
- Package allowlist and exact tarball Pi-load smoke
- Linux CI baseline and SHA-pinned Actions
- Inert release example until npm OIDC and GitHub approval environment are configured
- README, AGENTS, development, release, security, contribution, changelog, domain, ADR, diagnostics, configuration, storage, and smoke guidance
- Audit and adoption skills when the target intends to carry them

## Preservation rules

Preserve target extension behavior, feature tests, domain facts, supported-platform claims, configuration semantics, storage formats, security facts, and stronger existing controls. Adapt generic blueprint files to target identity. Never copy blueprint repository URLs or reference-only publication claims into a release-ready target.

## Completion

Run `npm run verify:ci` and the target's packed Pi-load smoke. Run documented target-specific real usage when available. Write `.pi-extension-template.json` with `standardVersion` set to `2026-08-27` only after all required checks pass and the final diff preserves target intent.
