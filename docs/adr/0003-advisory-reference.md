# ADR 0003: Linked Advisory Reference

## Status

Accepted. Supersedes [ADR 0001](0001-reference-blueprint.md) and [ADR 0002](0002-agent-driven-adoption.md).

## Decision

Replace the executable blueprint and adoption skills with portable, linked operation prompts that help agents explore, learn from Pi-owned resources, interview the user, act within authorization, and verify the outcome. Keep recommendations advisory and retain optional scripts only for demonstrated stable mechanics.

## Rationale and consequences

Fixed scaffolds and copied host knowledge impose choices that vary across projects and drift with upstream behavior. The reference instead owns engineering questions and decision guidance; source-aware review, local link checks, and representative setup and audit usage provide evidence without claiming target compliance or universal host compatibility.
