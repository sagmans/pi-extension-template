# Contributing

This repository is a general reference blueprint and does not accept contributions. Anyone may use and adapt it under the [MIT License](LICENSE).

When adapting this file for a target repository that accepts contributions, define:

1. Where contributors should report non-sensitive bugs and proposals.
2. How contributors should privately report vulnerabilities or private data exposure.
3. What intent, scope, regression proof, and real-usage evidence a change requires.
4. Which verification, package-content, security, privacy, documentation, compatibility, and release checks must pass.
5. Which generated output, credentials, prompts, sessions, and personal paths must remain untracked.
6. Which branch, commit, signing, and DCO rules apply under the target's governance.

Keep release preparation separate from feature work. Remove this file when the target repository does not accept contributions.
